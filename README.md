# Portfolio Enzo Flament

Site statique prêt à publier gratuitement avec GitHub Pages.

## Publier le site
1. Connecte-toi à GitHub avec le compte `Enzo-fla`.
2. Crée un dépôt public nommé exactement `Enzo-fla.github.io`.
3. Envoie à la racine du dépôt `index.html`, `style.css`, `script.js` et le dossier `assets`.
4. Dans Settings → Pages, choisis `Deploy from a branch`, branche `main`, dossier `/ (root)`, puis Save.
5. Vérifie l'adresse `https://Enzo-fla.github.io/` une fois le déploiement terminé.

## QR code
Crée le QR code seulement après avoir vérifié que le site est public et accessible. Il devra pointer vers l'adresse finale du site. Tu pourras ensuite l'insérer dans Canva.

## À vérifier avant publication
- Confirmer les dates, descriptions et statuts de chaque projet.
- Ajouter les liens directs vers les dépôts/démonstrations que tu souhaites rendre publics.
- Vérifier le téléphone et l'adresse e-mail avant de les afficher publiquement.
- Remplacer la photo si tu préfères une autre image.
